Deletion with crashed admissions or an unfinished key transition stays denied and requires proven drain/recovery; suspension has no automatic reactivation. No instant crypto-shredding is claimed. Future financial reference inventories/rotation/erasure must include the existing encrypted profile. Hosted CI custody, native Unity secure-storage/browser/callback integration and physical validation remain their owning scopes.
