Production rejects local provider/control custody; managed provider and independently permissioned production control adapter remain deployment gates, not fake implementations.

Production managed key provider and independently permissioned control adapter are intentionally unselected/unimplemented, not placeholders. Their restore/clone fencing, key-retention/rotation and backup drills must pass before deployment. Local SQLite cannot detect a physically restored older copy with the same valid authority; its operational quarantine requirement is documented in [persistence](../persistence.md), never a production guarantee. Crashed admissions require proven writer termination before privileged repair.

PR-03 owns authenticated identity binding and real user ownership constraints. PR-04 owns encrypted financial schemas, typed payload codecs, checkpoints, live-reference migration/retirement and financial transaction consistency. Operational/legal retention and production custody integration remain explicit deployment prerequisites; hosted Linux CI custody is unresolved.
