# ADR 0020 — Grounded Alquimista and gated stateless provider

Status: Accepted for explicitly authorized PR-09.A local scope; real provider approval is not inferred.

Decision: preserve PR-00.SEC's coarse-context policy. Reporting's exact compact facts stay backend-only; AI derives reviewed finding codes and coarse period class. A real model selects/orders source-backed reviewed narrative variants and questions; the backend composes their inert text. No unrestricted generated prose is displayed/stored. This intentionally constrains wording to make both numerical and qualitative grounding decidable, rather than promising a regex can detect arbitrary semantic hallucinations. No model response is fabricated when unavailable. UX discloses model selection/organization plus reviewed text, separate from deterministic values.

Adapter: OpenAI stateless Responses, pinned gpt-5.4-mini-2026-03-17, reasoning none, strict static JSON schema, no tools/background/store/retries. Narrow provider interface has no DB/domain capabilities. Configuration is unavailable by default; secret-file key and an expiring project/model/endpoint-specific operator review record are required. The record documents verified no-training/ZDR/regions/subprocessors terms; it is an operational attestation, not technical proof obtained by this PR. Live financial processing remains blocked without actual approval. No skill requires this gate: it comes from [AI provider policy](../domains/ai.md#provider-and-result-contract).

One synchronous attempt is admitted transactionally, then all DB locks/DEK scopes are released before network. PostgreSQL uniqueness and owner guard deduplicate; attempts are not durable jobs and are never resumed/re-dispatched after crash. Revocation prevents new admissions and discards late output; already-delivered remote processing cannot be undone. Terminal failure retry is a new explicit user intent under durable quotas, never an automatic provider retry. Context/fingerprint/source refs stay in runtime/encrypted binding only; no prompt/context archive. Results expire no later than source artifact, within security's 30-day maximum.

Primary sources fetched 2026-10-18: [model snapshot/features](https://developers.openai.com/api/docs/models/gpt-5.4-mini), [structured outputs](https://developers.openai.com/api/docs/guides/structured-outputs), [data controls](https://developers.openai.com/api/docs/guides/your-data). store:false does not remove default abuse logs without applicable ZDR controls. Structured-output schemas may be retained as system data: use a static global catalogue schema, never per-user dynamic enums/values. Endpoint account settings/terms/model eligibility need operational verification; no paid/live request was authorized by reading public docs.
