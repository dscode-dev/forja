# Forja

Mobile financial-health RPG. Product and architectural authority start in [AGENTS.md](AGENTS.md).

Development setup, pinned tools and commands: [development workflow](docs/development.md). Native Unity import and physical iPhone 15 Pro Max validation: [mobile workflow](docs/mobile-development.md). Current bounded work and evidence: [PR-09.A](docs/prs/PR-09.A.md).
